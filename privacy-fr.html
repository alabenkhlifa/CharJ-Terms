Politique de confidentialité de Charj

Dernière mise à jour : 16 avril 2026

Charj est une application mobile gratuite, sans publicité, qui aide les propriétaires de véhicules électriques en Tunisie à trouver des bornes de recharge. Cette politique explique quelles données nous collectons et comment nous les utilisons.

Résumé

  • Nous collectons le minimum de données nécessaires pour faire fonctionner l'application.
  • Nous ne vendons jamais vos données.
  • Nous n'utilisons aucun réseau publicitaire ni traceur tiers.
  • Nous n'exigeons aucun compte pour utiliser Charj.

Ce que nous collectons

Données de localisation

Lorsque vous l'autorisez, Charj utilise la position de votre appareil pour : - Centrer la carte sur votre position - Calculer les distances jusqu'aux bornes proches - Trier les listes de bornes par distance

Votre position n'est jamais transmise à nos serveurs et reste utilisée uniquement sur votre appareil.

Contributions communautaires

Si vous soumettez une borne ou signalez un problème, nous stockons sur nos serveurs : - Un identifiant d'appareil anonyme généré aléatoirement (utilisé uniquement pour afficher le compteur de vos contributions) - Le nom, la position, le type de connecteur, la puissance, les notes et les photos que vous fournissez - L'horodatage de votre contribution

Vous pouvez effacer votre identifiant d'appareil à tout moment en réinstallant l'application.

Données techniques

Charj peut mettre en cache localement des données de bornes sur votre appareil pour un usage hors-ligne. Ce cache est stocké uniquement sur votre appareil.

Ce que nous ne collectons PAS

  • Noms, adresses e-mail, numéros de téléphone
  • Identifiants ou mots de passe
  • Historique de navigation ou analyses comportementales
  • Contacts, photos (sauf celles que vous soumettez volontairement) ou autres fichiers personnels de votre appareil
  • Journaux de plantage ou télémétrie (au moment de la rédaction)

Services tiers

Charj s'appuie sur : - Google Maps pour les tuiles de carte et la navigation. La politique de confidentialité de Google s'applique : https://policies.google.com/privacy - Supabase pour l'hébergement de la base de données. Politique de confidentialité Supabase : https://supabase.com/privacy - Open Charge Map pour les données de base des bornes. Aucune donnée utilisateur n'est envoyée à Open Charge Map.

Vos droits

À tout moment, vous pouvez : - Révoquer les autorisations de localisation dans les paramètres de votre appareil - Supprimer toutes les données locales de l'application en désinstallant Charj - Demander la suppression d'une contribution que vous avez faite en ouvrant un ticket GitHub : https://github.com/alabenkhlifa/CharJ/issues

Enfants

Charj convient à tous les âges et ne collecte pas sciemment de données auprès d'enfants.

Modifications de cette politique

En cas de modification, nous mettrons à jour la date « Dernière mise à jour » ci-dessus et inclurons un résumé des changements.

Contact

Des questions ? Ouvrez un ticket à https://github.com/alabenkhlifa/CharJ/issues
